# Настройка и работа с клоакой

## Типы клоаки

Наш сервис предоставляет возможность использовать следующие типы:

1. Whitepage by 1sarafan (системный).
2. 404 error.

## Какой тип лучше всего использовать?

Для FB отлично работает 404 error. Для Google лучше использовать системный White Page, здесь клоака играет большую роль.

## Стоит ли отключать клоаку?

Для Tier-1 и Tier-2 гео отключать не стоит. А в случае с Tier-3 — однозначно да, так как любые лишние запросы делают загрузку страницы дольше, что критично сказывается на конверсии.&#x20;
