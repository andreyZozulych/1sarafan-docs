# Макросы для PWA

При настройке описаний PWA-приложений и комментариев можно использовать макросы — это позволит создавать более гибкие и эффективные воронки взаимодействия с пользователями.

* `{date}` — Дата в формате ДД.ММ.ГГГГ.\
  _&#x412; макрос можно добавить смещение по дням, указав +1d или -1d, например: {date-1d}._
* `{name}` — Название приложения.
* `{Random=(X,Y)}` — Выведет случайное число в указанном диапазоне от X до Y.
* `{text1|text2|text3}` — Выберет случайный вариант из указанных текстов.
* `{dayOfWeek}` — День недели.
* `{dateOfMonth}` — Число месяца.
* `{monthName}` — Название месяца.
