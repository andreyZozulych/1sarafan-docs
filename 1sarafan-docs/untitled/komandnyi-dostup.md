# Командный доступ

**Командный доступ** — инструмент, позволяющий распределять роли и управлять правами участников внутри одного продукта.

\
Система поддерживает несколько типов ролей с различными уровнями доступа и возможностями.

1. **Байер**

Обычный пользователь сервиса.

* Видит только собственные PWA и соответствующую статистику.
* Можно включить отображение сторонних PWA, Push, Pixel и Сплит.



2. **Teamlead**

Руководитель команды.

* Видит все PWA и статистику всех байеров, закреплённых за ним.
* Может добавлять и удалять участников с ролью **Байер** в пределах своей команды.
* Можно включить отображение сторонних PWA, Push, Pixel и Сплит.



3. **Owner**

Организатор команды.

* Обладает всеми правами роли **Teamlead**.
* Может добавлять пользователей с ролями **Teamlead** и **Финансист**.
* Управляет структурой команды и распределением ролей.



4. **Финансист**

Пользователь с доступом к финансовому функционалу.

* Имеет доступ только к операциям, связанным с пополнением и управлением балансом аккаунта.

***

Для создания или подключения команды пользователь с ролью **Owner** должен:

1. В личном кабинете нажать на свой аватар в верхней панели.
2. Выбрать пункт **"Create team"**.
3. Указать название для новой команды.

После создания команды в интерфейсе появится возможность переключения между **личным аккаунтом** и **командным пространством**.
